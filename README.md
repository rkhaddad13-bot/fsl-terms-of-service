# FSL — FIFA Futsal League Terms of Service

Official Terms of Service website for FSL (FIFA Futsal League).

## Overview

This is a static HTML website that displays the official Terms of Service for the FSL Discord bot and league management system. The site features:

- **Dark Modern Design** - Professional dark theme with smooth scrolling
- **Sticky Navigation** - Easy access to all 10 sections
- **Responsive Layout** - Fully mobile-friendly
- **Fast Loading** - Single HTML file with embedded CSS

## Features

The Terms of Service cover:

1. **Use of FSL** - Service overview and features
2. **User Conduct** - Expected behavior and prohibited actions
3. **League Decisions** - Staff authority and dispute resolution
4. **Matches & Results** - Match management and accuracy
5. **Transfers & Teams** - Team operations and rule enforcement
6. **Bot Availability** - Service reliability disclaimer
7. **Data & Information** - Data storage and usage
8. **Third-Party Services** - Discord Terms integration
9. **Changes to These Terms** - Update policy
10. **Contact** - Support information

## Deployment

### Option 1: GitHub Pages

1. Go to repository settings
2. Navigate to **Pages** section
3. Set source to `main` branch, `/root` directory
4. Your site will be live at: `https://rkhaddad13-bot.github.io/fsl-terms-of-service/`

### Option 2: Direct Hosting

Simply host the `index.html` file on any web server.

## Customization

To edit the Terms of Service:

1. Open `index.html`
2. Modify content within the `<main>` section
3. Update the "Last Updated" date
4. Commit and push changes
